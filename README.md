# Мои 3 дела

Личный трекер задач без аккаунта, сервера и сетевых запросов. Все данные
хранятся в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Vite выведет адрес вида `http://localhost:5173/`. Для проверки системных
уведомлений открывайте приложение на `localhost` или по HTTPS.

Другие команды:

```bash
npm run build    # проверка типов и production-сборка в dist/
npm run preview  # локальный просмотр production-сборки
npm run lint     # oxlint
```

## Возможности

- Быстрое добавление: только название, `Enter` создаёт задачу и возвращает
  фокус в поле.
- Полная форма: название, описание, срок, приоритет. При создании срок не
  может быть в прошлом; при редактировании прошлая дата допустима.
- Разделы «Сегодня», «Предстоящие», «Завершённые» с счётчиками.
- «Сегодня»: группы «Просрочено» → «На сегодня» → «Без срока» и плашка
  «Просрочено · N».
- Удаление с подтверждением и отменой в течение 6 секунд.
- Экспорт и импорт JSON, восстановление после повреждённого хранилища.
- Синхронизация открытых вкладок через событие `storage`.
- Светлая тема, клавиатурная навигация, адаптив от 375 px.

## Хранение данных

| Ключ                        | Содержимое                              |
| --------------------------- | --------------------------------------- |
| `tracker.tasks.v1`          | Задачи и время последнего изменения      |
| `tracker.settings.v1`       | Настройки уведомлений                    |
| `tracker.lastNotifiedAt.v1` | Время последней системной сводки         |

Данные не отправляются на сервер и не синхронизируются между устройствами.
Очистка данных сайта или браузера удаляет задачи. Перед очисткой скачайте
резервную копию: «Настройки» → «Скачать резервную копию».

Формат резервной копии:

```json
{
  "app": "personal-task-tracker",
  "version": 1,
  "exportedAt": "2026-11-04T10:00:00.000Z",
  "tasks": []
}
```

Импорт заменяет текущий список задач целиком после подтверждения. Файл
проверяется полностью: версия, типы полей, допустимые приоритеты и статусы,
реальные календарные даты, уникальность UUID и согласованность
`status = done` ⇔ `completedAt != null`. Максимальный размер файла — 5 МБ.

## Уведомления

- Сводка внутри интерфейса показывается при каждой загрузке, если есть
  просроченные задачи или задачи на сегодня. Её можно скрыть.
- Системные уведомления выключены по умолчанию. Разрешение запрашивается
  только при включении тумблера в настройках.
- Системная сводка показывается один раз за загрузку и только при
  `Notification.permission === "granted"` и включённом тумблере.
- При нескольких открытых вкладках уведомление показывает только одна:
  используется Web Locks и отметка `tracker.lastNotifiedAt.v1`, дубли в окне
  5 секунд подавляются. Без Web Locks работает fallback через `localStorage`.
- В обычной вкладке iOS Safari системных уведомлений нет — остаётся сводка
  внутри интерфейса. По LAN-адресу (`http://192.168…`) нет secure context,
  поэтому системные уведомления недоступны.

## Ограничения MVP

- Нет облачной синхронизации, аккаунтов и совместной работы.
- Нет тёмной темы, PWA, офлайн-режима и push-уведомлений.
- Нет повторяющихся задач, тегов, поиска и фильтров.
- Поддерживаются актуальные версии Chrome, Safari, Firefox и Edge.

## Стек

React 19, TypeScript, Vite 8, Zustand 5, обычный CSS. Без UI-китов, CDN и
внешних шрифтов — используются системные шрифты.
